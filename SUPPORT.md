# Поддержка FileScope

## Каналы

- **GitHub Issues** — воспроизводимые ошибки, конкретные запросы функций, задачи и проблемы документации.
- **GitHub Discussions организации Veilbyte** — вопросы, идеи и общая помощь с использованием.
- **SECURITY.md** — только приватные сообщения об уязвимостях.

## Перед обращением

Проверьте README, документацию, существующие Issues и Discussions. В обращении укажите:

- версию FileScope;
- Windows 10/11, редакцию и номер сборки;
- архитектуру системы;
- способ запуска: installer или portable;
- проверяемый тип объекта без прикрепления вредоносного содержимого;
- точные шаги воспроизведения;
- ожидаемый и фактический результат;
- очищенные логи и скриншоты.

Удалите из материалов токены, IP-адреса, cookies, имена пользователей, локальные пути, URL с секретами и другие чувствительные данные.

## Ограничения поддержки

Могут быть закрыты без подробного ответа обращения, которые:

- не заполнены по шаблону;
- дублируют существующую задачу;
- не относятся к FileScope;
- не содержат воспроизводимых данных;
- требуют нарушить `LICENSE` или `RESPONSIBLE_USE.md`;
- раскрывают уязвимость или чувствительные данные публично;
- содержат реальные вредоносные образцы.

Veilbyte не гарантирует срок ответа, реализацию функции, исправление каждой ошибки или поддержку всех окружений. Приоритет получают безопасность, потеря данных, стабильность и актуальная версия.

## Поддерживаемые версии

По умолчанию поддерживается текущая стабильная major-версия. Для FileScope до выхода 1.0 основным поддерживаемым каналом является последний опубликованный релиз `0.x`. Исправления для более старых minor-версий выпускаются по возможности.
