# FileScope

FileScope — desktop-приложение для Windows, предназначенное для понятной проверки ссылок, файлов, архивов, программ и браузерных расширений до запуска.

> Репозиторий находится на раннем этапе разработки первой UI-версии. Настоящие механизмы анализа, удаление файлов, карантин и сетевые проверки пока не реализованы.

## Принципы первой версии

- интерфейс полностью на русском языке;
- работа без обязательного подключения к интернету;
- отсутствие автоматической отправки пользовательских данных;
- только безопасные встроенные демонстрационные объекты;
- модульная архитектура для последующего подключения анализаторов;
- Tauri + React + TypeScript;
- тёмная тема является приоритетной.

## Ветки

- `main` — стабильные релизные версии;
- `develop` — интеграционная ветка;
- `feature/*` — разработка функций;
- `fix/*` — исправления;
- `release/*` — подготовка релизов.

Прямые изменения в `main` после начальной инициализации не допускаются. Все изменения проходят через Pull Request.

## Статус

Начат этап **Foundation**: структура монорепозитория, архитектурные документы, frontend/Tauri-основа, локализация, дизайн-токены, тестирование и CI.
