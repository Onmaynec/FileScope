# FileScope

FileScope — desktop-приложение для Windows, предназначенное для понятной проверки ссылок, файлов, архивов, программ и браузерных расширений до запуска.

> Версия 0.1.0 является UI-прототипом продукта. Она не выполняет настоящий анализ, не удаляет и не изменяет пользовательские файлы и не отправляет данные во внешние сервисы.

## Возможности v0.1.0

- русскоязычный интерфейс;
- тёмная и светлая темы;
- работа без обязательного подключения к интернету;
- экраны проверки ссылок, файлов, архивов и программ;
- встроенные безопасные демонстрационные отчёты;
- четыре уровня риска;
- mock-карантин;
- режим разработчика;
- системный трей;
- подготовка Windows x64 NSIS-установщика;
- модульная архитектура для будущих анализаторов.

## Локальный запуск

Требования:

- Node.js 22;
- pnpm 10.14;
- Rust stable;
- системные зависимости Tauri 2 для Windows.

```bash
pnpm install
pnpm dev
```

Запуск desktop-оболочки:

```bash
pnpm --filter @filescope/desktop tauri dev
```

Сборка Windows-приложения и EXE-установщика:

```bash
pnpm --filter @filescope/desktop build:desktop
```

## Проверки качества

```bash
pnpm --filter @filescope/desktop typecheck
pnpm --filter @filescope/desktop test
pnpm --filter @filescope/desktop build
```

## Ветки

- `main` — стабильные релизные версии;
- `develop` — интеграционная ветка;
- `feature/*` — разработка функций;
- `fix/*` — исправления;
- `release/*` — подготовка релизов.

Прямые изменения в `main` не допускаются. Изменения проходят через Pull Request.

## Безопасность и приватность

- настоящие вредоносные образцы в репозитории отсутствуют;
- все демонстрационные объекты вымышлены и имеют `isDemo: true`;
- приложение не заявляет абсолютную безопасность объекта;
- пароли архивов не сохраняются;
- телеметрия выключена;
- внешние API в первой версии отсутствуют.
