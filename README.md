# FileScope

FileScope — desktop-приложение для Windows, предназначенное для понятной проверки ссылок, файлов, архивов, программ и браузерных расширений до запуска.

> Версия 0.1.0 является первой полностью кликабельной UI-версией продукта. Она не выполняет настоящий анализ, не удаляет и не изменяет пользовательские файлы и не отправляет данные во внешние сервисы.

## Возможности v0.1.0

- onboarding первого запуска и обязательное предупреждение об отсутствии абсолютной гарантии;
- русскоязычный интерфейс;
- системная, тёмная и светлая темы;
- работа без обязательного подключения к интернету;
- экраны проверки ссылок, файлов, архивов, программ и расширений;
- безопасный нативный файловый диалог без запуска анализа;
- встроенные демонстрационные отчёты с `isDemo: true`;
- четыре пользовательских уровня риска;
- вкладки результата и режим разработчика;
- локальный mock-карантин и исключения;
- настройки приватности, окна и mock-обновлений;
- экран FileScope Free / Pro без платёжной системы;
- системный трей с быстрыми действиями;
- сохранение темы, onboarding, sidebar, размера и положения окна;
- подготовка Windows x64 NSIS-установщика;
- unit-тесты, Playwright smoke-тесты и GitHub Actions.

## Локальный запуск

Требования:

- Node.js 22;
- pnpm 10.14;
- Rust stable;
- системные зависимости Tauri 2 для Windows.

```bash
pnpm install --no-frozen-lockfile
pnpm dev
```

Запуск desktop-оболочки:

```bash
pnpm --filter @filescope/desktop tauri dev
```

Сборка Windows-приложения и EXE-установщика:

```bash
pnpm --filter @filescope/desktop build:desktop
```

## Структура

- `apps/desktop` — React/Vite frontend и Tauri shell;
- `packages/contracts` — доменные модели и интерфейсы анализаторов;
- `docs/architecture` — архитектурные решения;
- `docs/design-system` — дизайн-токены;
- `docs/product` — границы и требования версии.

## Ветки

- `main` — стабильные релизные версии;
- `develop` — интеграционная ветка для проверки;
- `feature/*` — разработка функций;
- `fix/*` — исправления;
- `release/*` — подготовка релизов.

Прямые изменения в `main` не допускаются. Версия 0.1.0 сначала объединяется с `develop` и только после ручной проверки переносится в `main` отдельным Pull Request.

## Безопасность и приватность

- настоящие вредоносные образцы в репозитории отсутствуют;
- все демонстрационные объекты вымышлены и имеют `isDemo: true`;
- выбранному пользователем объекту не присваивается фиктивный вердикт;
- приложение не заявляет абсолютную безопасность объекта;
- пароли архивов не сохраняются;
- clipboard не читается автоматически;
- телеметрия выключена;
- внешние API и production-сервер обновлений в первой версии отсутствуют.
