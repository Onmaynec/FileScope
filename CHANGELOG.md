# Журнал изменений

Все значимые изменения FileScope описываются в этом файле.

## [Не выпущено]

## [0.3.3] — не выпущено

### Исправлено

- закрыты SSRF, DNS rebinding, redirect и credentials-риски активного URL-анализатора;
- файловый SHA-256 и структурный разбор используют один открытый объект и отклоняют reparse points;
- изменение файла во время анализа формирует типизированную ошибку вместо сомнительного отчёта;
- отмена ожидает подтверждения Rust backend и работает во время hashing, ZIP traversal, DNS и HTTP;
- browser fallback больше не выдаёт отдельный production verdict;
- версия приложения больше не дублируется строковыми литералами в UI и экспорте;
- история отчётов мигрируется на schema v1 с резервной копией legacy-данных;
- drag-and-drop, текст «Загрузить файлы», custom Select и master-detail очередь исправляют UX массовой проверки.

### Добавлено

- `JobRegistry`, типизированные ошибки и resource budgets;
- `schemaVersion`, `appVersion`, `analyzerVersion`, `ruleSetVersion`, `createdBy`, `analysisCompleteness`;
- SHA-256 payload в JSON/HTML export с явной пометкой об отсутствии цифровой подписи;
- поиск, фильтры, virtualization и навигация по завершённым отчётам;
- security и architecture документация v0.3.3.

### Безопасность

- локальные/private/metadata сети блокируются до соединения;
- каждый redirect повторно проходит DNS/IP-проверку;
- credentials redaction применяется до сохранения и экспорта;
- анализируемые файлы не запускаются, ZIP не извлекается на диск.


## [0.3.2] — не выпущено

### Добавлено

- команда `pnpm doctor` для локальной проверки Node.js, pnpm, Rust, Cargo, MSVC, Windows SDK, WebView2 и свободного места;
- копирование краткого результата проверки вместе с уровнем риска, форматом и SHA-256;
- явный статус частичного анализа для RAR, 7Z, повреждённых PE и остановки защитным лимитом.

### Исправлено

- одинаковые PE-import evidence нормализуются и отображаются один раз;
- повтор одного и того же индикатора с одинаковыми доказательствами больше не увеличивает итоговую оценку;
- сообщения об ошибках чтения файлов, защитных лимитов, ZIP, DNS и timeout стали понятнее;
- наличие таблицы Authenticode больше не формулируется как проверенная доверенная подпись.

### Сборка

- добавлены и отслеживаются `pnpm-lock.yaml` и `apps/desktop/src-tauri/Cargo.lock`;
- CI и release workflow используют `pnpm install --frozen-lockfile`;
- Rust-тесты и `cargo check` выполняются с `--locked`;
- после установки и production-сборки проверяется неизменность lock-файлов.

### Безопасность

- дедупликация не ослабляет полные injection- и download-and-execute комбинации;
- `pnpm doctor` не изменяет систему и не отправляет сведения во внешние сервисы;
- новые зависимости и сетевые разрешения не добавлены.

## [0.3.1] — 2026-08-05

### Исправлено

- одиночные распространённые Windows API, включая `VirtualAlloc` и `ShellExecuteW`, больше не переводят законный PE-файл в категорию «Высокий риск»;
- отсутствие Authenticode больше не считается самостоятельным признаком вредоносности и имеет низкий информационный вес;
- оценка PE теперь различает отдельные системные функции и действительно опасные комбинации импорта;
- подписанные установщики и обычные desktop-приложения не должны получать высокий вердикт только из-за одного API повышенного внимания;
- ярлык, окно, панель задач, системный трей, portable EXE и NSIS-установщик используют единый утверждённый фиолетовый логотип FileScope.

### Безопасность

- полный набор `VirtualAllocEx + WriteProcessMemory/NtWriteVirtualMemory + CreateRemoteThread/NtCreateThreadEx` сохраняет высокий уровень риска;
- сочетание сетевой загрузки и последующего запуска сохраняет высокий уровень риска;
- неполные комбинации работы с чужим процессом остаются предупреждением и требуют контекстной проверки;
- добавлены Rust unit-тесты для FileScope-подобного, Telegram-подобного, injection-chain и download-and-execute сценариев.

### Изменено

- версия frontend, contracts, Tauri и Rust-пакета обновлена до 0.3.1;
- Tauri перед development- и production-сборкой автоматически генерирует Windows iconset из единого SVG-источника;
- интерфейс и экран «О программе» уточняют, что одиночный системный импорт не является доказательством угрозы;
- документация описывает независимость локальной оценки FileScope от внешних ML-вердиктов антивирусных поставщиков.

### Известное внешнее ограничение

- исходный portable EXE v0.3.0 получил единичное ML-срабатывание Microsoft при отсутствии детектов у большинства остальных движков; результат стороннего антивируса нельзя гарантированно изменить кодом FileScope;
- для устойчивой репутации Windows-релизов необходимы Authenticode/Artifact Signing и отправка подтверждённых ложных срабатываний через официальный портал Microsoft.

## [0.3.0] — 2026-08-05

### Исправлено

- нажатие на системную кнопку закрытия теперь надёжно обрабатывается в Rust/Tauri backend;
- в режиме «Сворачивать в трей» главное окно скрывается, а приложение продолжает работать в системном трее;
- в режиме «Закрывать полностью» FileScope корректно завершает процесс;
- пункт «Выйти» в меню трея сохраняет принудительное полное завершение приложения;
- официальная Windows release-сборка больше не открывает отдельное консольное окно;
- закрытие сторонней консоли больше не может случайно завершить release EXE FileScope.

### Добавлено

- отдельное нативное состояние lifecycle окна с безопасным значением по умолчанию `tray`;
- синхронизация настройки поведения кнопки закрытия между React-интерфейсом и Rust backend;
- Rust unit-тесты переключения поведения окна;
- русские release notes для v0.3.0.

### Изменено

- версия frontend, contracts, Tauri и Rust-пакета обновлена до 0.3.0;
- обработка `close-requested` перенесена из JavaScript-слушателя в нативный backend;
- README и экран «О программе» обновлены для v0.3.0;
- release EXE собирается с Windows GUI subsystem, при этом debug-сборки сохраняют возможность вывода консоли.

### Управление и документация

- репозиторий перенесён в организацию `Veilbyte`;
- проект классифицирован как `Public Source-Available`;
- добавлена Veilbyte Restricted Source License 1.0;
- добавлена локальная политика репозитория;
- обновлены правила участия и security-процесс;
- добавлены Code of Conduct, Responsible Use, Support, Brand Policy и CLA;
- добавлены CODEOWNERS, Pull Request template и локальные Issue Forms;
- настроены Dependabot и автоматическая проверка Policy Pack;
- закреплена модель `Issue → branch → Pull Request → CI → Review → Merge`.

## [0.2.0] — 2026-08-05

### Добавлено

- реальное локальное аналитическое ядро на Rust;
- вычисление SHA-256 потоковым чтением;
- определение фактического типа файла по сигнатуре;
- поиск двойных расширений и несоответствия расширения содержимому;
- базовый анализ Windows PE: архитектура, точка входа, секции, энтропия и импорты;
- определение наличия каталога Authenticode без проверки доверенности сертификата;
- пассивный анализ HTTP/HTTPS URL без сетевого обращения;
- поиск Punycode, IP вместо домена, встроенных учётных данных, большого числа поддоменов, вложенных адресов и исполняемых загрузок;
- ручная активная URL-проверка с DNS и минимальным HEAD/Range-запросом;
- структурный анализ ZIP без извлечения содержимого на диск;
- проверка path traversal, глубины, числа элементов, распакованного объёма и степени сжатия;
- обнаружение исполняемых файлов и вложенных архивов внутри ZIP;
- объяснимый Rule Engine с доказательствами и рекомендациями;
- новый модульный App Shell для функциональной версии;
- реальная история локальных отчётов;
- экспорт отчётов в JSON и автономный HTML;
- защитные настройки лимитов анализа;
- новые unit-тесты Rust и TypeScript;
- новые Playwright smoke-сценарии функционального интерфейса.

### Изменено

- интерфейс по умолчанию переключён с демонстрационной оболочки 0.1.0 на функциональную оболочку 0.2.0;
- вкладки файлов, ссылок и архивов используют единое рабочее пространство анализа;
- результаты больше не используют фиктивные mock-вердикты для выбранных пользователем объектов;
- версия frontend, Tauri и Rust-пакета обновлена до 0.2.0;
- сохранены улучшенные анимации и полная поддержка `prefers-reduced-motion`;
- светло-голубой текст на светлых поверхностях заменён контрастной синей и тёмной семантической палитрой;
- добавлена автоматическая Playwright-проверка контраста ключевых текстовых элементов светлой темы.

### Безопасность

- исследуемые файлы не запускаются и не модифицируются;
- ZIP не извлекается на диск;
- пассивный URL-анализ не выполняет DNS или HTTP-запросы;
- активная сеть включается только вручную после явного согласия;
- защитные лимиты нельзя полностью отключить;
- HTML-экспорт экранирует пользовательские значения;
- файлы и отчёты не отправляются во внешние сервисы.

### Ограничения

- RAR и 7Z распознаются как форматы, но структурно не разбираются;
- Authenticode определяется по наличию каталога сертификатов, без построения цепочки доверия;
- активный URL-анализ не выполняет JavaScript и не загружает страницу целиком;
- поведенческий анализ и Hyper-V Sandbox не входят в 0.2.0.

## [0.1.0] — первая UI-версия

### Добавлено

- desktop-оболочка на Tauri для Windows 10 и Windows 11 x64;
- onboarding первого запуска с предупреждением об ограничениях продукта;
- русскоязычный интерфейс с системной, тёмной и светлой темами;
- боковая навигация, адаптивный App Shell и сохранение состояния sidebar;
- экраны «Главная», «Проверка», «Ссылки», «Файлы», «Архивы», «Программы», «Отчёты», «Карантин», «Настройки», «Подписка» и «О программе»;
- нативный файловый диалог без автоматического запуска анализа;
- четыре пользовательских уровня риска;
- безопасные встроенные демонстрационные отчёты;
- демонстрационное дерево архива с визуальным предупреждением о двойном расширении;
- интерфейс списка программ без фиктивной оценки реальных приложений;
- вкладки результата, причины, поведение, сеть, метаданные и технические mock-данные;
- локальный mock-карантин с восстановлением и удалением демонстрационных записей;
- локальный список исключений;
- режим разработчика с предупреждением перед включением;
- системный трей с быстрыми действиями;
- сохранение размера и положения окна;
- настройки поведения кнопки закрытия;
- mock-сервисы обновлений, лицензии и карантина;
- централизованные ресурсы русской локализации;
- дизайн-токены, доступные focus-состояния и поддержка Reduce Motion;
- ESLint, TypeScript strict, Vitest и Playwright smoke-тесты;
- CI для lint, typecheck, unit/e2e-тестов, frontend-сборки и Windows x64 NSIS-сборки;
- русская архитектурная, продуктовая и security-документация.

### Безопасность

- выбранные пользователем объекты не получают демонстрационный вердикт;
- пароли архивов не сохраняются;
- clipboard не читается автоматически;
- реальные файлы не удаляются, не изменяются и не помещаются в карантин;
- внешние сетевые API и телеметрия отсутствуют;
- настоящие вредоносные образцы в репозитории отсутствуют.
