# Политика безопасности FileScope

## Поддерживаемая версия

До публикации стабильного релиза поддерживается ветка `develop` и текущая подготовка версии 0.1.0.

## Сообщение об уязвимости

Не публикуйте сведения об уязвимости в открытом Issue. Используйте приватный канал владельца репозитория или GitHub Security Advisory, когда он будет включён.

В сообщении укажите:

- затронутую версию и платформу;
- точные шаги воспроизведения;
- возможные последствия;
- минимальный безопасный пример без реального вредоносного кода;
- предлагаемый вариант исправления, если он известен.

## Запрещённые материалы

В репозиторий нельзя добавлять:

- реальные вредоносные образцы;
- стилеры, RAT, кейлогеры, ransomware или загрузчики;
- активные вредоносные URL;
- приватные ключи, сертификаты подписи и токены;
- конфиденциальные пользовательские данные.

Для тестирования интерфейса разрешены только вымышленные mock-данные с `isDemo: true`.

## Приватность версии 0.1.0

Версия 0.1.0 не содержит внешних API, не загружает выбранные файлы, не читает clipboard автоматически и не сохраняет пароли архивов.
