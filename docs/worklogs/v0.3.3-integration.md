# Интеграция очистки истории и исправление очереди

Работа ведётся поверх актуального `develop` FileScope 0.3.3.

- интеграция функции из `feature/clear-report-history`;
- адаптация к schema v1 и новой модели истории;
- исправление отображения длинных имён и метаданных в очереди;
- обязательные frontend, Playwright, Rust, Tauri и Windows проверки.
