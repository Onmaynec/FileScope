# FileScope v0.4.0 — Windows history QA harness

`scripts/windows-v040-history-qa.ps1` сокращает ручную часть release QA для DPAPI, restart, portable policy и full clear. Harness предназначен для PowerShell 7 (`pwsh`) на Windows и по умолчанию работает с Tauri app-data `%APPDATA%\com.filescope.desktop\history`.

## Гарантии harness

- live-режимы не изменяют Rust/Tauri history store;
- DPAPI plaintext существует только в памяти текущего процесса PowerShell и не выводится в консоль/файлы;
- `Snapshot` сохраняет только имена generation, размеры, SHA-256, protection label и timestamps — без report payload;
- `AssertForeignUserRejected` проверяет SHA-256 до/после и не переписывает переданную generation;
- `SelfTest` создаёт и удаляет только собственный временный каталог в `%TEMP%`;
- сеть не используется.

## 1. CI self-test

Windows job основного CI обязан выполнить:

```powershell
pwsh -NoProfile -File scripts/windows-v040-history-qa.ps1 -Mode SelfTest
```

Self-test проверяет совместимость wrapper `FSDPAPI1` с Windows DPAPI CurrentUser, отсутствие synthetic plaintext marker в ciphertext, decrypt/schema validation, snapshot/restart comparison, portable layout assertion и clear assertion на временных данных.

## 2. Inspect реального профиля

После запуска v0.4.0:

```powershell
pwsh -NoProfile -File scripts/windows-v040-history-qa.ps1 -Mode Inspect
```

Вывод содержит только metadata history files. Ожидаемый root: `%APPDATA%\com.filescope.desktop\history`.

Если тест проводится на копии app-data:

```powershell
pwsh -NoProfile -File scripts/windows-v040-history-qa.ps1 -Mode Inspect -AppDataRoot 'D:\qa\filescope-profile'
```

## 3. DPAPI current-user + plaintext leak check

Создать в FileScope тестовый report с уникальным безопасным marker, например `FSQA-2026-08-09-A`, затем выполнить:

```powershell
pwsh -NoProfile -File scripts/windows-v040-history-qa.ps1 `
  -Mode AssertCurrentUser `
  -PlaintextMarker 'FSQA-2026-08-09-A'
```

PASS означает одновременно:

- есть минимум одна `reports-v2-*.bin` generation;
- нет orphan `.tmp`;
- healthy-профиль не содержит `.json` plaintext generation;
- `.bin` начинается с `FSDPAPI1`;
- marker не встречается в ciphertext;
- Windows DPAPI CurrentUser успешно расшифровывает generation под текущим user;
- decrypted envelope имеет `storageVersion=2`, `reportSchemaVersion=1` и массив `reports`.

Harness намеренно не печатает decrypted report payload.

## 4. Restart stability

Перед закрытием FileScope, когда никаких новых анализов/изменений history больше не планируется:

```powershell
pwsh -NoProfile -File scripts/windows-v040-history-qa.ps1 `
  -Mode Snapshot `
  -SnapshotPath "$env:TEMP\filescope-v040-before-restart.json"
```

Полностью завершить FileScope через Quit, запустить снова и, не создавая/не удаляя reports, выполнить:

```powershell
pwsh -NoProfile -File scripts/windows-v040-history-qa.ps1 `
  -Mode AssertRestartStable `
  -BaselinePath "$env:TEMP\filescope-v040-before-restart.json"
```

PASS означает, что generation names + SHA-256 не изменились при обычном restart без history write.

## 5. Full clear + restart

В UI выполнить «Удалить всю историю», полностью завершить FileScope и запустить снова. Затем:

```powershell
pwsh -NoProfile -File scripts/windows-v040-history-qa.ps1 -Mode AssertCleared
```

PASS означает, что app-data history directory отсутствует либо не содержит известных `reports-v2-*` generation/temp payload. Settings/limits проверяются отдельно через UI, поскольку harness намеренно не трогает другие application stores.

## 6. Portable policy

Portable EXE запускать из отдельного чистого каталога. После создания history в portable-сеансе выполнить:

```powershell
pwsh -NoProfile -File scripts/windows-v040-history-qa.ps1 `
  -Mode AssertPortable `
  -PortableExecutable 'D:\FileScopePortable\filescope.exe'
```

PASS означает, что рядом с EXE нет `history` directory и `reports-v2-*`, а ожидаемый app-data root находится вне portable directory. Затем `AssertCurrentUser` должен подтвердить DPAPI generation в per-user app-data.

## 7. Реальный cross-user DPAPI isolation

Под source user выбрать одну `.bin` generation и скопировать её в общий QA-каталог **без удаления оригинала**. Зафиксировать source username.

Войти под другим Windows user и выполнить:

```powershell
pwsh -NoProfile -File scripts/windows-v040-history-qa.ps1 `
  -Mode AssertForeignUserRejected `
  -GenerationPath 'C:\Users\Public\FileScope-QA\reports-v2-source.bin' `
  -ExpectedSourceUser 'SourceUserName'
```

PASS требует, чтобы DPAPI CurrentUser decrypt завершился ошибкой, а SHA-256 файла до/после совпал. Если decrypt неожиданно успешен — это **NO-GO**.

Для cross-machine проверки тот же файл перенести на вторую Windows machine и выполнить ту же команду под другим user.

## 8. Что harness не заменяет

Harness не заменяет:

- реальную migration v0.3.x через UI/WebView → Rust/Tauri store;
- принудительное завершение процесса ровно во время publication;
- реальный Windows ACL/locked-file failure;
- визуальную проверку UI status/badges;
- analyzer regression QA.

Эти проверки остаются в `v0.4.0-manual-qa.md` до фактического выполнения.

## GO / NO-GO для harness-блока

GO только если `SelfTest`, `AssertCurrentUser`, restart stability, full clear, portable layout и cross-user reject дают PASS на финальном artifact/HEAD.

NO-GO при plaintext marker в `.bin`, отсутствии `FSDPAPI1`, неожиданном `.json` в healthy DPAPI profile, невозможности decrypt под тем же user, успешном decrypt под другим user/machine, появлении history рядом с portable EXE или восстановлении generation после full clear/restart.
