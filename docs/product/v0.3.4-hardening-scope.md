# Scope hardening-pass v0.3.4

Цель этого прохода — довести PR #78 до состояния, где автоматические проверки зелёные и владелец может начинать ручной Windows QA без известных release blockers.

Hardening не включает пользовательские функции v0.4.0 (Tauri history storage, DPAPI, retention/privacy settings), но исправляет дефекты текущего production behavior и границ безопасности, обнаруженные до релиза v0.3.4.
