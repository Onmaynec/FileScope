# Regression: future report schema inside current history storage

## Сценарий

`storageVersion` может оставаться поддерживаемым, когда `reportSchemaVersion` уже принадлежит более новой версии приложения. Кроме того, malicious/corrupted envelope может заявить текущую report schema, но содержать отдельный report с future `schemaVersion`.

## Требуемое поведение

- статус `unsupported`;
- исходный raw payload остаётся байт-в-байт неизменным;
- новый отчёт не разрешает перезапись такого envelope;
- UI показывает защитный read-only status;
- отдельный fixture `future-report-schema.json` входит в readiness checks.
