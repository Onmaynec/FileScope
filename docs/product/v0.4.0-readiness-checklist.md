# FileScope v0.4.0 readiness checklist

## Foundation

- [x] UI отделён от конкретного history backend асинхронным repository contract.
- [x] Report schema и storage envelope version разделены.
- [x] Legacy migration fixtures и backup policy зафиксированы.
- [x] Future/corrupted/oversized storage не перезаписывается.
- [x] Privacy minimization helpers подготовлены и протестированы.
- [x] Быстрые property tests входят в PR CI.
- [x] Bounded fuzz targets и read-only workflow подготовлены.

## Authoritative history storage

- [x] Реализован Rust/Tauri history storage v2 в app-data каталоге.
- [x] Запись выполняется через новую generation, временный файл, `sync_all` и атомарную публикацию через rename; предыдущая валидная generation сохраняется для recovery.
- [x] Rust storage ограничивает число отчётов и размер payload.
- [x] Future `storageVersion`, future `reportSchemaVersion`, corrupted и oversized generation не перезаписываются автоматически.
- [x] При повреждении последней generation Rust backend способен открыть предыдущую валидную generation.
- [x] Tauri commands load/inspect/save/replace/rewrite/delete/clear зарегистрированы в production runtime.
- [x] Rust regression tests, `cargo test --locked`, `cargo check --locked`, Tauri build, Windows x64 и NSIS проходят в PR CI.
- [ ] Выполнен ручной Windows test аварийного завершения/перезапуска непосредственно во время publication generation.

## localStorage → Tauri migration

- [x] Production runtime проверяет Rust/Tauri storage раньше legacy WebView history.
- [x] Legacy history читается для миграции в read-only режиме без предварительного rewrite/backup promotion.
- [x] Перед записью в новый store к legacy report применяется privacy minimization.
- [x] После успешной миграции новые reports записываются только в Rust/Tauri storage, без double-write в localStorage.
- [x] Future/corrupted/oversized legacy history блокирует автоматическую миграцию и остаётся нетронутой.
- [x] Frontend regression tests проверяют migration, privacy minimization, authoritative Rust store и отсутствие double-write.
- [ ] Выполнена ручная миграция реальной истории v0.3.x на Windows с restart/rollback-проверкой.
- [ ] Проверена политика повторного запуска после частичного отказа очистки legacy payload.

## Privacy и retention

- [x] Добавлен переключатель сохранения новых reports.
- [x] Добавлен retention: current session / 1 / 7 / 30 дней / без автоудаления.
- [x] Session-only и disabled persistence сохраняют новый report только в памяти текущего процесса и не удаляют существующую persistent history.
- [x] 1/7/30-day retention физически переписывает authoritative Rust store без устаревших reports.
- [x] Полный путь по умолчанию минимизируется до basename.
- [x] URL credentials удаляются всегда; query/fragment сохраняются только по явной пользовательской policy.
- [x] Sensitive response headers не сохраняются в history.
- [x] Privacy minimization идемпотентна и применяется также к ранее сохранённой history через policy rewrite.
- [x] Settings UI показывает backend, фактический размер persistent store и количество reports.
- [x] Полная очистка охватывает Rust generations, session history и известные legacy report payload/backups.
- [ ] Полная очистка подтверждена ручным Windows restart-test без восстановления report data.

## Windows DPAPI protection

- [x] Новые Windows generations защищаются системным `CryptProtectData` до записи на диск.
- [x] Чтение использует `CryptUnprotectData`; при ошибке decrypt generation идёт в corrupted/recovery path, а не трактуется как empty.
- [x] Используется current-user scope; `CRYPTPROTECT_LOCAL_MACHINE` запрещён readiness-check.
- [x] `CRYPTPROTECT_UI_FORBIDDEN` исключает неожиданный системный prompt во время persistence.
- [x] Windows DPAPI failure не имеет plaintext fallback.
- [x] Новые encrypted generations имеют binary wrapper `FSDPAPI1` и `.bin` suffix.
- [x] Валидные ранние plaintext v2 generations читаются как migration source и удаляются только после успешной DPAPI publication.
- [x] Future/corrupted plaintext generations не удаляются автоматическим protection cleanup.
- [x] Tauri command `history_protection_status` и Settings UI показывают фактический DPAPI/plaintext/mixed/empty/unavailable status.
- [x] Windows CI выполняет реальный DPAPI encrypt/decrypt round-trip и проверяет отсутствие контрольного plaintext secret в generation.
- [ ] DPAPI current-user isolation подтверждена ручным тестом между двумя Windows users/машинами.

## Portable mode

- [x] Portable policy описана: portable относится к EXE, persistent history остаётся в per-user app-data.
- [x] Persistent portable history использует тот же current-user DPAPI и не хранит ключи/секреты рядом с EXE.
- [x] Копирование portable EXE само по себе не переносит history.
- [x] Явный JSON/HTML export отделён от encrypted history store и остаётся пользовательской переносимой операцией.
- [ ] Поведение portable app-data и невозможность расшифровки скопированной generation другим user/PC подтверждены вручную.
