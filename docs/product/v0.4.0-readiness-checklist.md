# FileScope v0.4.0 readiness checklist

## Foundation

- [x] UI отделён от конкретного history backend асинхронным repository contract.
- [x] Report schema и storage envelope version разделены.
- [x] Legacy migration fixtures и backup policy зафиксированы.
- [x] Future/corrupted/oversized storage не перезаписывается.
- [x] Privacy minimization helpers подготовлены и протестированы.
- [x] Быстрые property tests входят в PR CI.
- [x] Bounded fuzz targets и read-only workflow подготовлены.

## Authoritative history storage

- [x] Реализован Rust/Tauri history storage v2 в app-data каталоге.
- [x] Запись выполняется через новую generation, временный файл, `sync_all` и атомарную публикацию через rename; предыдущая валидная generation сохраняется для recovery.
- [x] Rust storage ограничивает число отчётов и размер payload.
- [x] Future `storageVersion`, future `reportSchemaVersion`, corrupted и oversized generation не перезаписываются автоматически.
- [x] При повреждении последней generation Rust backend способен открыть предыдущую валидную generation.
- [x] Tauri commands load/inspect/save/replace/delete/clear зарегистрированы в production runtime.
- [x] Rust regression tests, `cargo test --locked`, `cargo check --locked`, Tauri build, Windows x64 и NSIS прошли на HEAD `4196b0265c91858bbc26f40797fd0766fec94306` (CI #233).
- [ ] Выполнен ручной Windows test аварийного завершения/перезапуска непосредственно во время publication generation.

## localStorage → Tauri migration

- [x] Production runtime проверяет Rust/Tauri storage раньше legacy WebView history.
- [x] Legacy history читается для миграции в read-only режиме без предварительного rewrite/backup promotion.
- [x] Перед записью в новый store к legacy report применяется privacy minimization.
- [x] После успешной миграции новые reports записываются только в Rust/Tauri storage, без double-write в localStorage.
- [x] Future/corrupted/oversized legacy history блокирует автоматическую миграцию и остаётся нетронутой.
- [x] Frontend regression tests проверяют migration, privacy minimization, authoritative Rust store и отсутствие double-write.
- [ ] Выполнена ручная миграция реальной истории v0.3.x на Windows с restart/rollback-проверкой.
- [ ] Проверена политика повторного запуска после частичного отказа очистки legacy payload.

## Privacy, retention и Windows protection

- [ ] Добавлены retention и privacy settings UI.
- [ ] Добавлено отображение фактического размера history store и статуса защиты.
