# Release notes FileScope

Перед публикацией версии создайте файл:

```text
docs/releases/vMAJOR.MINOR.PATCH.md
```

Файл используется workflow `.github/workflows/release.yml` как официальное описание GitHub Release.

## Обязательная структура

```markdown
# FileScope vX.Y.Z

Краткое описание назначения версии.

## Главное

- ключевые возможности;
- заметные исправления.

## Безопасность и приватность

- изменения модели угроз;
- новые сетевые действия;
- изменения обработки файлов и данных.

## Совместимость

- поддерживаемые Windows и архитектуры;
- breaking changes;
- миграция настроек и отчётов.

## Известные ограничения

- ограничения анализаторов;
- неподдерживаемые форматы;
- риски ложных срабатываний.

## Проверка загрузки

Сверьте SHA-256 installer и portable EXE с `SHA256SUMS.txt`.
```

## Правила

- release notes ведутся на русском языке;
- версия должна совпадать с `package.json`, desktop package, contracts package, `Cargo.toml`, `tauri.conf.json` и CHANGELOG;
- нельзя перезаписывать опубликованный тег или скрыто заменять бинарные файлы;
- предварительные версии публикуются с флагом Pre-release;
- ограничения и security-изменения нельзя скрывать за общими формулировками.
