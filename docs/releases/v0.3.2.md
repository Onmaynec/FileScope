# FileScope v0.3.2

FileScope v0.3.2 — небольшое обновление стабильности сборки и качества локального анализа.

## Главное

- одинаковые нормализованные признаки больше не увеличивают оценку несколько раз;
- повторяющиеся PE-import evidence группируются и отображаются один раз;
- добавлена команда `pnpm doctor` для проверки локального окружения сборки;
- зависимости Node.js и Rust зафиксированы lock-файлами;
- CI и release workflow проверяют воспроизводимость установки и сборки;
- отчёт явно показывает, когда анализ выполнен частично;
- краткий результат и SHA-256 можно скопировать из интерфейса.

## Воспроизводимая сборка

В репозитории отслеживаются:

- `pnpm-lock.yaml` для workspace-зависимостей;
- `apps/desktop/src-tauri/Cargo.lock` для Rust/Tauri-зависимостей.

CI использует `pnpm install --frozen-lockfile`, `cargo test --locked` и `cargo check --locked`. После production-сборки проверяется, что оба lock-файла не изменились.

Локальная установка:

```bash
pnpm install --frozen-lockfile
```

## Диагностика окружения

Команда:

```bash
pnpm doctor
```

локально проверяет:

- Node.js 22;
- pnpm 10.14.0;
- Rust и Cargo;
- target `x86_64-pc-windows-msvc`;
- `link.exe` и `cl.exe`;
- Windows SDK;
- Microsoft Edge WebView2 Runtime;
- свободное место;
- наличие утверждённого SVG-источника иконок.

Команда не устанавливает компоненты, не изменяет систему и не выполняет сетевые запросы.

## Rule Engine

Одинаковые evidence нормализуются без учёта регистра и DLL-префикса. Например, повторный `VirtualAlloc` из `kernel32.dll` и `KernelBase.dll` отображается и учитывается один раз.

Повтор одного и того же индикатора с теми же нормализованными доказательствами также не увеличивает итоговую оценку.

При этом сильные комбинации сохраняются:

- `VirtualAllocEx + WriteProcessMemory/NtWriteVirtualMemory + CreateRemoteThread/NtCreateThreadEx` — высокий риск;
- сетевой API загрузки вместе с `WinExec` или `ShellExecute` — высокий риск;
- неполная комбинация работы с другим процессом — предупреждение.

## Интерфейс и отчёты

- точная версия `0.3.2` показывается в настройках, боковой панели и разделе «О программе»;
- кнопка «Кратко» копирует уровень риска, объект, оценку, формат, SHA-256 и число признаков;
- наличие Authenticode-каталога описывается отдельно от проверки доверия издателя;
- RAR и 7Z получают явную пометку частичного анализа;
- повреждённый PE и остановка защитным лимитом также обозначаются как неполный результат;
- системные ошибки чтения, DNS, timeout, ZIP и защитных лимитов переводятся в понятные сообщения.

## Безопасность и приватность

- анализируемые файлы не запускаются;
- ZIP не извлекается на диск;
- файлы и отчёты не отправляются во внешние сервисы;
- `pnpm doctor` не собирает и не передаёт телеметрию;
- новые сетевые разрешения не добавлены;
- реальные вредоносные образцы не добавлены;
- дедупликация не ослабляет сильные правила Rule Engine.

## Поддерживаемая платформа

- Windows 10 x64;
- Windows 11 x64;
- NSIS installer для текущего пользователя;
- portable x64 EXE.

ARM64 и другие ОС официально не поддерживаются.

## Известные ограничения

- наличие Authenticode-каталога не равно проверенной цепочке доверия;
- RAR и 7Z распознаются без структурного разбора;
- активный URL-анализ не исполняет JavaScript и не загружает страницу целиком;
- статический анализ не наблюдает поведение процесса;
- внешний антивирусный false positive может сохраняться до решения поставщика;
- sandbox, VirusTotal API и автоматический updater не входят в v0.3.2.
