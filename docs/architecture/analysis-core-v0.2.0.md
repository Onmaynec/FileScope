# Аналитическое ядро FileScope v0.2.0

## Общая схема

Версия 0.2.0 разделяет пользовательский интерфейс и привилегированную работу с локальными объектами:

```text
React UI
  ↓ типизированный invoke
Tauri commands
  ↓
Rust analysis modules
  ├─ file
  ├─ url
  ├─ archive
  └─ rules
  ↓
AnalysisReport
  ↓
локальная история / JSON / HTML
```

Frontend не читает произвольные локальные файлы напрямую. Он получает путь только после действия пользователя в системном диалоге и передаёт его Tauri-команде.

## Модули Rust

### `analysis/types.rs`

Содержит сериализуемые доменные типы:

- `AnalysisReport`;
- `AnalysisLimits`;
- `ThreatIndicator`;
- `RiskLevel`;
- `PeAnalysis`;
- `UrlAnalysis`;
- `ArchiveAnalysis`.

Поля сериализуются в camelCase для прямого использования TypeScript-интерфейсом.

### `analysis/rules.rs`

Rule Engine не скрывает причину вердикта. Каждый анализатор формирует набор признаков, после чего движок:

1. суммирует ограниченные баллы;
2. учитывает наличие признаков `high` и `critical`;
3. ограничивает итоговую оценку диапазоном 0–100;
4. выбирает пользовательский уровень риска.

Критический признак всегда переводит результат в «Опасный объект», даже если его числовой вклад ниже общего порога.

### `analysis/file.rs`

Файловый анализатор:

- проверяет тип пути и размер до полного чтения;
- вычисляет SHA-256 потоково блоками;
- читает только ограниченный префикс для определения типа и общей энтропии;
- при необходимости разбирает PE через `goblin`;
- не загружает очень крупные PE целиком;
- не выполняет исследуемый файл.

### `analysis/url.rs`

Пассивная команда выполняет только синтаксический разбор URL.

Активная команда вызывается отдельно и:

- использует заданный таймаут;
- ограничивает перенаправления;
- сначала выполняет DNS-разрешение;
- предпочитает HEAD;
- при несовместимости сервера использует GET с `Range: bytes=0-0`;
- сохраняет только небольшой разрешённый набор заголовков;
- не исполняет JavaScript.

### `analysis/archive.rs`

ZIP-анализатор читает центральный каталог и метаданные записей. Содержимое файлов не извлекается на диск и не запускается.

До и во время обхода применяются лимиты:

- размер исходного архива;
- число записей;
- заявленный распакованный объём;
- глубина путей;
- коэффициент сжатия.

Путь каждой записи проверяется через `enclosed_name` и дополнительные правила абсолютных и родительских компонентов.

## Frontend

`src/features/analysis` разделён на:

- `api` — вызовы Tauri и браузерный fallback пассивного URL-разбора;
- `model` — TypeScript-типы, локальное хранилище, лимиты и экспорт;
- `ui` — рабочее пространство анализа, отчёт, история и настройки.

Браузерный fallback существует только для разработки интерфейса. Он способен выполнить реальный пассивный URL-разбор, но явно отказывает в доступе к локальным файлам и активной сети.

## Локальное хранение

В 0.2.0 отчёты и настройки хранятся на устройстве пользователя. История ограничена 250 последними отчётами, чтобы избежать бесконтрольного роста.

Отчёт содержит путь или URL проверенного объекта. Пользователь должен учитывать это перед передачей экспортированного JSON или HTML третьим лицам.

## Модель угроз и границы

Ядро защищается от:

- случайного запуска исследуемого файла;
- подмены расширения;
- двойного расширения;
- чрезмерных файлов;
- ZIP path traversal;
- заявленной архивной бомбы;
- чрезмерного количества записей;
- слишком глубокой структуры;
- автоматического сетевого обращения при вставке URL;
- HTML-инъекции в экспортируемый отчёт.

Ядро 0.2.0 не защищает от всех неизвестных форматов, уязвимостей используемых парсеров, DNS rebinding, динамического вредоносного поведения или логики, раскрывающейся только после запуска. Эти задачи требуют следующих уровней изоляции и анализа.

## Тестирование

Frontend-пайплайн включает:

- ESLint;
- TypeScript strict;
- Vitest;
- production build;
- Playwright.

Windows-пайплайн включает:

- `cargo fmt --check`;
- `cargo test`;
- `cargo check`;
- Tauri production build;
- NSIS packaging.

Артефакты рабочей версии сохраняются только в GitHub Actions и не публикуются как Release до решения владельца.
