# Дизайн-система FileScope

## Принцип интерфейса

Сначала пользователь видит понятный вывод, затем объяснение, рекомендацию, причины и только после этого технические данные.

## Основные цвета

| Токен | Значение |
|---|---|
| Primary | `#2563EB` |
| Primary Hover | `#1D4ED8` |
| Secondary | `#7C3AED` |
| Background Dark | `#0F1117` |
| Surface Dark | `#161A22` |
| Surface Elevated | `#1C212B` |
| Border Dark | `#2A2F3A` |
| Text Primary Dark | `#F2F4F8` |
| Text Secondary Dark | `#A5ACB8` |

## Семантические состояния

- без признаков угрозы — `#22C55E`, щит с галочкой и текстовое пояснение;
- требуется осторожность — `#F59E0B`, предупреждающая иконка и описание;
- высокий риск — `#F97316`, иконка риска и рекомендация;
- опасный объект — `#EF4444`, щит с предупреждением и явное действие.

Смысл не передаётся только цветом.

## Типографика

Основной стек: `Segoe UI Variable`, `Segoe UI`, `Inter`, `Arial`, `sans-serif`.

- H1 — 28/36 px, Semibold;
- H2 — 22/28 px, Semibold;
- H3 — 18/24 px, Semibold;
- основной текст — 14/20 px;
- вторичный текст — 13/18 px;
- технические значения — Cascadia Mono или JetBrains Mono, 12–13 px.

## Сетка и радиусы

Используется сетка 4 px. Основные отступы: 4, 8, 12, 16, 20, 24, 32, 40, 48 и 64 px.

- поля — 8 px;
- кнопки и стандартные карточки — 12 px;
- крупные карточки — 16 px;
- модальные окна и onboarding — 20–24 px;
- pill-компоненты — 999 px.

## Доступность

- видимый `focus-visible`;
- клавиатурная навигация;
- минимальная область взаимодействия 40×40 px;
- `aria-label` для кнопок без текста;
- `role="dialog"` и `aria-modal` для модальных окон;
- поддержка `prefers-reduced-motion`;
- интерфейс сохраняет работоспособность при масштабировании Windows до 200%.
